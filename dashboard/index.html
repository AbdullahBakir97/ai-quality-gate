    How It Works

    🔍

    AI Fingerprint Detection

    Analyzes vocabulary, sentence structure, and patterns unique to AI-generated text like "delve", "leverage", and uniform paragraph lengths.

    📊

    Quality Scoring

    Scores issues and PRs on specificity, reproduction steps, linked issues, test coverage, and description quality (0-100).

    ✅

    GitHub Checks

    Shows pass/warn/fail status directly on pull requests with detailed breakdown of all signals and quality checks.

    🏷️

    Auto-Labeling

    Applies labels like "ai-generated", "ai-suspected", "low-quality", and "high-quality" based on configurable thresholds.

    ⚙️

    Per-Repo Config

    Drop a .github/ai-gate.yml to customize thresholds, actions (comment, label, request-changes, close), and exempt users.

    🛡️

    Hallucination Detection

    Catches fake API references, nonexistent version numbers, and vague documentation links that signal AI hallucination.

    Easy Configuration

    Add .github/ai-gate.yml to customize behavior per repository

    # .github/ai-gate.yml

ai:
  warn: 50         # Score to trigger warning
  fail: 80         # Score to trigger failure
  action: comment  # comment | label | request-changes | close

quality:
  minimum: 30      # Minimum quality score to pass
  action: comment  # What to do when quality is too low

analyze:
  issues: true
  pull_requests: true

exempt:
  users: [trusted-bot, core-maintainer]
  labels: [bot, automated]
  bots: true
